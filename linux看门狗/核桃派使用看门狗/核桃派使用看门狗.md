# 核桃派使用看门狗


## 1️⃣ 配置文件 `/etc/watchdog.conf`

关键配置项：

```ini
# 使用硬件看门狗设备
watchdog-device = /dev/watchdog

# 超时时间（秒）
watchdog-timeout = 16

# 刷新间隔（秒）
interval = 5

# 使用 settimeout 刷新方式
watchdog-refresh-use-settimeout = yes

# 前台实时优先级
realtime = yes
priority = 1
```

> 其他选项（ping、文件检查、负载、温度等）可以根据需要启用，但不是必须。

---

## 2️⃣ 确认硬件 /dev/watchdog 可用

```bash
ls -l /dev/watchdog
# 如果不存在：
modprobe sunxi-wdt   # 你的硬件是 sunxi 系列
# 或软件看门狗：
modprobe softdog
```

---

## 3️⃣ 手动测试 watchdog

```bash
sudo watchdog -F -v
```

* `-F`：前台运行
* `-v`：显示详细日志
* 输出会显示：

  ```
  watchdog now set to 16 seconds
  hardware watchdog identity: sunxi-wdt
  Running ioctl-based refresh
  still alive after 1 interval(s)
  ```
* 可确认 watchdog 刷新正常。

---

## 4️⃣ systemd 开机自启

创建 `/etc/systemd/system/watchdog.service`：

```ini
[Unit]
Description=Hardware Watchdog Daemon
After=network.target

[Service]
ExecStart=/usr/sbin/watchdog -F -v
Type=simple
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
```

操作：

```bash
sudo systemctl daemon-reload
sudo systemctl enable watchdog   # 开机自启
sudo systemctl start watchdog
sudo systemctl status watchdog
sudo journalctl -f -u watchdog   # 实时查看日志
```

✅ 这样：

* watchdog 会开机自启
* systemd 不会误判退出循环重启
* 日志里可以持续看到 `"still alive after X interval(s)"`

---

## 5️⃣ 测试 watchdog 功能

小心测试（机器会重启）：

```bash
sudo systemctl stop watchdog
# 等待超过 watchdog-timeout 秒（16 秒），机器应自动重启
```

> 建议在软看门狗 `softdog` 上测试，避免硬件意外重启。

---

### 总结

1. 配置 `/etc/watchdog.conf` → 指定设备、超时、刷新间隔
2. 确认硬件 `/dev/watchdog` 可用
3. 手动运行 `watchdog -F -v` 验证功能
4. systemd 配置 `ExecStart=/usr/sbin/watchdog -F -v` → 开机自启
5. 用 `journalctl -f -u watchdog` 实时查看心跳
6. 可选测试重启确认 watchdog 功能
