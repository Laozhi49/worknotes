Vim 和一般的文本编辑器不一样，它是 **模式化编辑器**，有不同模式，每个模式下按键功能不同。

---

## 1️⃣ Vim 的三种主要模式

| 模式                     | 功能                   | 进入方式                                                                     |
| ---------------------- | -------------------- | ------------------------------------------------------------------------ |
| **普通模式（Normal Mode）**  | 移动光标、删除、复制、粘贴、保存、退出等 | 打开文件默认就在普通模式                                                             |
| **插入模式（Insert Mode）**  | 可以像普通编辑器一样输入文字       | 按 `i`（在光标前插入）、`I`（行首插入）、`a`（光标后插入）、`A`（行尾插入）、`o`（当前行下新开一行）、`O`（当前行上新开一行） |
| **命令模式（Command Mode）** | 执行保存、退出、查找替换等命令      | 在普通模式下按 `:` 进入                                                           |

> 小技巧：**按 Esc 键总能回到普通模式**。

---

## 2️⃣ 基本操作（普通模式）

### 光标移动

* `h` ← 左
* `j` ↓ 下
* `k` ↑ 上
* `l` → 右
* `0` 行首
* `^` 行首第一个非空字符
* `$` 行尾
* `w` 下一个单词首
* `e` 当前/下一个单词尾

### 编辑操作

* `x` 删除光标所在字符
* `dd` 删除整行
* `yy` 复制整行
* `p` 粘贴到光标后
* `u` 撤销
* `Ctrl + r` 重做

---

## 3️⃣ 插入模式

进入插入模式后，就像普通编辑器一样打字。
退出插入模式回普通模式：**Esc**

---

## 4️⃣ 命令模式（以 `:` 开头）

在普通模式下输入 `:` 进入：

| 命令              | 说明        |
| --------------- | --------- |
| `:w`            | 保存        |
| `:q`            | 退出        |
| `:wq` 或 `:x`    | 保存并退出     |
| `:q!`           | 不保存强制退出   |
| `:set number`   | 显示行号      |
| `:set nonumber` | 关闭行号      |
| `:help`         | 查看 Vim 帮助 |

---

## 5️⃣ 保存和退出常用组合

* 保存：`Esc` → `:w` → Enter
* 退出：`Esc` → `:q` → Enter
* 保存并退出：`Esc` → `:wq` → Enter
* 强制退出不保存：`Esc` → `:q!` → Enter

---

## 6️⃣ 快速小技巧

* `Ctrl + O`：在插入模式临时回到普通模式执行命令，然后回插入模式
* `u`：撤销操作
* `.`：重复上一次操作
* `/关键词`：查找关键词，`n` 下一个，`N` 上一个
